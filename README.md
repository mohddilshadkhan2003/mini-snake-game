A polished, responsive Snake game with a neon arcade UI, backed by a Spring Boot REST API for leaderboards. Designed to run as a single JAR or inside Docker for quick deployments.

Highlights
- Java 17 + Spring Boot 3.x
- REST endpoints: `/api/scores` (GET/POST) and `/api/health`
- OpenAPI/Swagger UI at `/swagger-ui.html`
- H2 persistence (in-memory by default)
- Static frontend served from Spring at `/`

Quick start (local, Maven)
```bash
# Run in dev
mvn spring-boot:run

# Build and run the jar
mvn clean package
java -jar target/mini-snake-game-1.0.0.jar
```
Open: http://localhost:8080
OpenAPI (Swagger UI): http://localhost:8080/swagger-ui.html
H2 console (dev): http://localhost:8080/h2-console (jdbc:h2:mem:snake)

Run with Docker
```bash
# build image
docker build -t mini-snake-game:latest .

# run image
docker run --rm -p 8080:8080 mini-snake-game:latest
```

Run with docker-compose
```bash
docker-compose up --build
# then open http://localhost:8080
```

Development notes
- API docs generated by springdoc-openapi; Swagger UI available at `/swagger-ui.html`.
- To publish a Docker image from CI, add DOCKERHUB_USERNAME and DOCKERHUB_TOKEN (or use GitHub Packages settings) and enable the publish job in the workflow.

Project structure
```text
src/main/java/com/example/snake
  SnakeGameApplication.java    # Spring Boot entry point
  controller/                  # HTTP controllers (ScoreController)
  model/                       # Score, Difficulty
  repository/                  # JPA repositories
  service/                     # Business logic
src/main/resources/static      # index.html, styles.css, app.js
pom.xml                        # Maven project
```
